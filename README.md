# 🖱️ Custom Cursor
A simple custom cursor built using *HTML, CSS, and JavaScript*. The cursor follows the mouse movement across the screen using JavaScript mouse events.

### 🛠️ Tech Stack
* HTML
* CSS
* JavaScript

### ✨ Features
* Custom cursor
* Real-time mouse tracking
* Simple and responsive UI
* No external libraries
